# 签到功能

到岗即结算：发送 `XX楼已到` 当场记时长，无需签退。每人每班次每天限一次。

## 命令

| 命令 | 说明 |
|------|------|
| `XX楼已到`（如 `文综楼已到`） | 到岗签到，当场结算时长并显示今日 / 累计 |
| `补签` | 显示补签格式说明 |
| `补签 姓名 日期 班次` | 为忘签到的成员补录一条记录，如 `补签 小明 2026-10-18 三班次` |

签到成功后自动输出统计（今日 / 累计），无需单独查询指令。

## 补签

- **格式**：`补签 姓名 日期 班次`，日期用 `YYYY-MM-DD`（如 `2026-10-18`）。
- **姓名**：按群成员匹配——先精确匹配群名片，没有匹配再匹配 QQ 昵称；找不到人会拒绝。
  重名时会回复候选列表（含 QQ），改用 `补签 姓名#QQ 日期 班次` 指定具体成员。
- **班次**：写配置里的班次名；晚班需带时长，写成 `晚班2` / `晚班3`。
- **时长**：固定班次取 `duration_hours`，晚班取后缀指定的时长。
- **时间**：在班次到岗时间起的 `makeup_window_minutes`（默认 15 分钟）内随机，且不会超过班次结束时间。
- 不能补签未来日期；同一成员同一天同一班次已有记录时不会重复写入。
- 群内任何人都可以使用补签。

## 时长规则

- **白天班次（一~四）**：固定录入时长 `duration_hours`（2 / 3 / 2 / 2 小时），发送 `XX楼已到` 即可。
- **晚班**：时长由群友带后缀指定——`XX楼已到+2` 记 2 小时（到 21 点），`XX楼已到+3` 记 3 小时（到 22 点）。
  - 晚班未带后缀（或后缀不在可选时长内）：提示重发，不结算、不落库。
  - 白天班次若误带 `+N`：提示固定时长班次无需带，不结算、不落库。
- **签到窗口**：各班次到岗 ~ 班次结束。
- **每人每班次每天只能签到一次**，重复发送会提示已签到过。

## 班次配置

编辑 `configs/checkin.yaml` 自定义班次。白天班次用 `duration_hours` 记固定时长；晚班用 `options_hours` 让群友通过 `+N` 后缀自选时长。

默认班次：

| 班次 | 到岗 | 班次结束 | 录入时长 |
|------|------|---------|---------|
| 一班次 | 07:40 | 09:20 | 2 小时 |
| 二班次 | 09:50 | 12:20 | 3 小时 |
| 三班次 | 14:10 | 15:50 | 2 小时 |
| 四班次 | 16:20 | 18:00 | 2 小时 |
| 晚班 | 19:20 | 22:00 | `XX楼已到+2` → 2 小时；`XX楼已到+3` → 3 小时 |

## 数据

- 数据文件默认存储在 `data/checkin_data.db`
- 每一条签到记录包含：群号、用户 QQ、用户昵称/群名片、日期、班次、录入时长（小时）、签到时间
- 默认不自动清理历史数据。如需自动清理，在 `configs/checkin.yaml` 中设置 `data.retain_days`（如 `retain_days: 90` 表示保留 90 天）

## 存储结构

```sql
records (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    group_id    TEXT NOT NULL,      -- 群号
    user_id     TEXT NOT NULL,      -- 用户 QQ
    user_name   TEXT DEFAULT '',    -- 昵称/群名片
    date        TEXT NOT NULL,      -- 签到日期
    period      TEXT NOT NULL,      -- 班次名称
    duration    INTEGER DEFAULT 0,  -- 录入时长（小时，签到即结算）
    time        TEXT                -- 签到时间(当日 HH:MM:SS)
)
```

通过 `group_id + user_id + date + period` 唯一索引保证每人每班次每天只能签到一次。
