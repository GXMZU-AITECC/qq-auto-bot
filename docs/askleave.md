# 请假功能

群里发 `请假 班次 [原因]` 当场登记并回复确认；每个班次到岗前会自动在群里提醒该班次谁请假（没人请假就不打扰）。

## 命令

| 命令 | 说明 |
|------|------|
| `请假 一班次 去医院` | 登记请假，当场回复确认 |
| `请假` | 只发这两个字会回复用法说明，不登记 |
| `取消请假 一班次` | 取消指定班次 |
| `取消请假` | 不带班次 = 取消**当天全部**请假 |
| `请假名单` | 看今天谁请假 |
| `请假名单 明天` | 看某天谁请假 |

登记成功后自动回复日期、班次、到岗时间和原因，无需单独查询。

## 日期写法

| 写法 | 含义 |
|------|------|
| 不写 | 默认今天 |
| `今天` / `明天` / `后天` | 按天偏移 |
| `10-20` | 当年 10 月 20 日（月份远小于当前月份时按跨年理解） |
| `2026-10-20` | 指定日期 |

写了日期但根本不成立（如 `13-45`）会提示换个写法，**不会静默按今天登记**。

## 班次写法

班次定义**不单独配置**，直接复用 `configs/checkin.yaml` 的 `checkin_shifts`，与签到认的是同一份，改时间点只改一处。

| 写法 | 说明 |
|------|------|
| `一班次` | 配置里的班次名，直接写 |
| `1班次` / `1班` | 数字简写，等价于 `一班次` |
| `晚自修` / `晚自习` | 等价于配置里的 `晚班` |
| `一班次 二班次` | 多个班次连写，空格或顿号分隔 |

- 只认上面这些明确写法，**不做「以晚开头就算晚班」的通配**：`请假 一班次 晚上加班` 里的「晚上加班」是原因，不会被当成晚班多登记一条。
- 一个都没认出来时回复可用班次清单，不登记、不落库。

## 取消规则

只有「确实没写班次」才取消当天全部；**写了但认不出时一条都不删**，先让群友确认：

| 输入 | 行为 |
|------|------|
| `取消请假` | 取消当天全部 |
| `取消请假 一班次` | 只取消一班次 |
| `取消请假 一版次`（打错字） | 不删任何记录，提示认不出并列出可用班次 |

## 到岗前提醒

后台长驻任务每分钟对一次表，某班次的 `到岗时间 - notify_before_minutes` 正好落在当前这一分钟时，把该班次的请假名单发到群里：

```
⏰ 一班次 30 分钟后开始（07:40 到岗）
今日请假：张三（去医院）、李四
```

- 只发**有该班次请假记录的群**，没人请假不打扰。
- 每个群每个班次每天只提醒一次，重复唤醒会去重。

## 配置

编辑 `configs/askleave.yaml`：

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enabled` | `false`（缺省） | 显式写 `true` 才启用；配置缺失时不启用，与 demo / schoolcalendar 保持一致 |
| `notify_before_minutes` | `30` | 提前多少分钟提醒；写成非数字时回落 30 |

## 数据

- 与签到功能共用 `config.yaml` 里 `data.file` 指向的 SQLite 库，只是用独立的 `leaves` 表，不引入第二份数据库配置，也不和签到数据混在一起。
- 如需自动清理历史数据，在 `config.yaml` 中设置 `data.retain_days`（如 `retain_days: 90` 表示保留 90 天）；未设置则默认不清理。

## 存储结构

```sql
leaves (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    group_id  TEXT NOT NULL,      -- 群号
    user_id   TEXT NOT NULL,      -- 用户 QQ
    user_name TEXT DEFAULT '',    -- 昵称/群名片
    date      TEXT NOT NULL,      -- 请假日期
    period    TEXT NOT NULL,      -- 班次名称
    reason    TEXT DEFAULT '',    -- 请假原因
    time      TEXT                -- 登记时间(当日 HH:MM:SS)
)
```

通过 `group_id + user_id + date + period` 唯一索引保证同一人同一天同一班次只记一条，重复登记会提示「已经登记过」而不是新增。
